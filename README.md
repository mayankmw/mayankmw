## `// 00x01` — THE EXPERIMENT

The internet is a collection of abstractions pretending to be solid.

Underneath the interfaces: protocols. Underneath the protocols: state machines. Underneath the state machines: edge cases nobody thought about at 2 AM.

This space exists to explore the interesting parts.

```c
while (consciousness != NULL) {
    observe(reality);
    question(abstractions);
    build(something_weird);
    if (it_works()) break;
    debug(universe);
}
```

**Research areas**

- Systems engineering & runtime internals
- Networks, protocols & distributed systems
- Databases, storage engines & data structures
- Reverse engineering & defensive security
- AI experiments, automation & weird little tools
- Generative visuals, terminal art & developer tooling
